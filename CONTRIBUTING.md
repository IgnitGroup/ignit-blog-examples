# Contributing

You can help improve these examples by reporting bugs, unclear instructions or suggestions through [GitHub Issues](https://github.com/IgnitGroup/ignit-blog-examples/issues). A GitHub account is required to create an issue.

## Report a problem

Check existing issues first. If the problem has not been reported, [create a new issue](https://github.com/IgnitGroup/ignit-blog-examples/issues/new) with:

- The article URL and example directory.
- Steps to reproduce the problem.
- The expected result and what actually happened.
- Relevant tool/provider versions and AWS Region, where applicable.
- A short, sanitized error message or log excerpt.

## Suggest an improvement

Open an issue describing the problem you want to solve and your proposed improvement. Documentation corrections, questions about an example and requests for additional examples are welcome.

## Sensitive information

Issues are public. Do not include credentials, Terraform state, saved plans, private configuration or customer data. Report security-sensitive findings privately to Ignit through the contact channel on [ignit.group](https://ignit.group/) instead of opening a public issue.

## How changes are handled

The Ignit team reviews issues and maintains the code. External contributions are accepted through issues; pull requests are reserved for repository collaborators.
